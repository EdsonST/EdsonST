# 🚀 Projeto em Destaque

# EXTRATUS

## Controle Financeiro Inteligente

O **EXTRATUS** é uma plataforma de controle financeiro desenvolvida para ajudar pessoas, motoristas autônomos e MEIs a compreenderem melhor suas finanças e tomarem decisões mais inteligentes.

A proposta vai além do simples registro de receitas e despesas.

O objetivo é transformar dados financeiros em clareza, organização e melhores decisões.
